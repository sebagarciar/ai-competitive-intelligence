# AI Competitive Intelligence Copilot — Luxury Fashion

An end-to-end pipeline that watches Chanel, Dior, and Gucci across public news, video, and social sources, then turns the noise into structured competitive-intelligence events, detected trends, and a weekly strategic brief — with **no paid LLM API required**.

Built as an applied AI/ML project: multi-source ingestion → NLP normalization & translation → local sentence embeddings → semantic deduplication → event classification (keyword + zero-shot NLI) → DBSCAN theme clustering → burst-based trend detection → LLM-synthesized brief, all served through a Streamlit dashboard.

## Highlights

- **7 ingestion sources** (RSS, brand sites, YouTube, Reddit, Bluesky, X/Grok, Webhose) with graceful degradation — any source missing an API key is skipped, not fatal
- **Multi-query social listening**: a query planner expands each brand into 8 search variants (`"{brand} pricing"`, `"{brand} vs {competitor}"`, …) for better recall on consumer chatter
- **Local-first ML**: sentence embeddings (`all-MiniLM-L6-v2`), zero-shot event classification, and brief synthesis (Llama 3.1 8B via Ollama) all run on-device — zero marginal cost per run
- **8-category event taxonomy** with burst-detection trend scoring, tuned and justified via an ablation study (`notebooks/evaluation.ipynb`)
- **Evaluation harness**: Precision@k, event-classification F1, and trend-formula ablation against human-labeled samples — not just a demo, a measured system
- **Streamlit dashboard**: weekly brief (+ PDF export), sentiment/perception charts, filterable event feed, and semantic search over the full corpus

## Quick Start — Dashboard Only

Explores the pre-computed data already checked into `data/intelligence.db` — no API keys needed.

```bash
pip install -r requirements.txt streamlit
streamlit run dashboard/app.py
```

## Quick Start — Full Pipeline

Re-runs ingestion, embedding, classification, and brief generation. Needs the ML/scraping stack, which is intentionally excluded from `requirements.txt` (that file is trimmed to dashboard-only deps to fit Streamlit Cloud's free-tier size limit):

```bash
# 1. Install dashboard + pipeline dependencies
pip install -r requirements.txt streamlit \
    sentence-transformers transformers torch scikit-learn \
    feedparser beautifulsoup4 trafilatura cloudscraper praw \
    langdetect deep-translator httpx

# 2. Copy and configure API keys — all optional, missing ones are skipped
cp .env.example .env

# 3. (Optional) Install Ollama for local LLM brief synthesis
brew install ollama
ollama pull llama3.1:8b
ollama serve &        # leave running in background

# 4. Run the full pipeline (ingest → process → analyze → brief)
python -m src.pipeline
# (or `python -m src.pipeline --no-llm` to skip LLM synthesis)

# 5. Launch the dashboard
streamlit run dashboard/app.py
```

The "Strategic Implications" section of the weekly brief is generated by a **locally-served Llama 3.1 8B Instruct** model via Ollama — no paid API calls. If Ollama isn't running, the brief automatically falls back to deterministic rule-based implications.

## How It Works

1. **Ingest** — pull from all sources; social sources use multi-query planning with retry on thin results
2. **Normalize** — clean HTML, standardize dates
3. **Language** — detect language, translate any non-English content to English (free-tier translation)
4. **Embed** — compute sentence embeddings with `all-MiniLM-L6-v2` (local model)
5. **Deduplicate** — URL exact-match + cosine similarity threshold (0.92)
6. **Extract** — classify event type: keyword scoring as a fast pre-filter, zero-shot NLI (`cross-encoder/nli-MiniLM2-L6-H768`) for ambiguous items
7. **Cluster** — DBSCAN on embeddings to discover semantic themes
8. **Trends** — burst detection formula (`0.45·burst + 0.27·sources + 0.18·impact + 0.10·sentiment`); flags Critical Events and Emerging Trends
9. **Brief** — generate a markdown weekly intelligence report, with an optional local-LLM strategic-implications section

## Data Sources

| Source | Type | Auth | Notes |
|---|---|---|---|
| Vogue Business / BoF / WWD / FT RSS | Fashion media | None | Brand-filtered |
| Chanel / Dior / Gucci official sites | Brand-owned | None | `official_source = True` |
| YouTube | Video | `YOUTUBE_API_KEY` | Channel + keyword search |
| Webhose.io | News API | `WEBHOSE_API_KEY` | Social share metrics |
| Reddit | Social media | `REDDIT_CLIENT_ID` / `REDDIT_CLIENT_SECRET` | Subreddit browse + keyword search |
| Bluesky | Social media | `BSKY_IDENTIFIER` / `BSKY_APP_PASSWORD` | AT Protocol search, app-password auth |
| X via Grok | Social media | `XAI_API_KEY` | Grok live X search, optional |

The pipeline degrades gracefully — missing API keys skip that source and continue. After each run it prints a per-source summary showing item counts and which sources were unavailable. Social adapters (Reddit, Bluesky, Grok) automatically retry with simplified queries if initial results are sparse.

### Social Listening — Query Planning

Social adapters use a **query planner** (`src/ingestion/query_planner.py`) that generates multiple search variants per brand instead of just the brand name:

```
Chanel → "Chanel", "Chanel review", "Chanel pricing",
          "Chanel collection", "Chanel quality",
          "Chanel alternatives", "Chanel vs Dior", "Chanel vs Gucci"
```

This improves coverage across consumer opinions, competitive comparisons, and product-specific discussions.

## Evaluation

`notebooks/evaluation.ipynb` provides a manual-labeling workflow against `src/evaluation.py`'s metric functions:
- Label the top 10 items by impact → **Relevance Precision@10**
- Label 20 event classifications → **Event F1 Score** (macro/weighted, via sklearn)
- Label the top 5 trends → **Trend Precision@5**
- **Trend-weight ablation**: compares 5 candidate scoring-weight configurations against unsupervised proxy metrics to justify the chosen formula without hand-labeling every trend
- **Classifier fine-tuning**: label ~150 events, train a `LogisticRegression` on the stored embeddings, compare against the keyword baseline
